# OP Auto Clicker 4.1 (Wayland Edition)
Production-ready, kernel-level input automation for Linux.

## Quick Start
1. Extract the zip.
2. Run: \`chmod +x launch.sh\`
3. Run: \`./launch.sh\`

The launcher will automatically detect missing dependencies or permissions, prompt for sudo once to configure \`uinput\` and install \`python-pyside6\` / \`python-evdev\`, and then instruct you to relogin. After relogging, running \`./launch.sh\` launches the app instantly.
